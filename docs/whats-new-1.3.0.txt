=== English ===
New in 1.3.0 — quality-of-life upgrades!

• Multiple save states: keep several save points per game — load, delete or add new ones from the in-game menu.
• Hold-to-fast-forward: speed through grinding and slow text with the new FF button.
• Customizable controls: adjust on-screen button size, position and opacity in Settings.
• Screen options: choose your aspect ratio and toggle pixel smoothing for a sharp retro look.
• PS1 BIOS setup guide added to Settings.

As always: only use files you legally own. No games or BIOS included.
